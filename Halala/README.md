# هللة 🪙: تطبيق مصاريفك بالهللة والريال

تطبيق آيفون يسجّل كل ريال يدخل حسابك أو يطلع منه:
- كل عملية لها فئة بصورة واسم، مثلًا ☕ قهوة، 🍔 مطاعم، 🛒 بقالة، ⛽ بنزين، والمبلغ تحتها.
- الصق رسالة البنك، والتطبيق يطلع منها المبلغ واسم المحل والفئة.
- إذا ربطته بالاختصارات، أي رسالة بنك توصلك تنسجل لحالها.
- إذا اخترت فئة لمحل، يحفظها ويستخدمها المرة الجاية.
- فيه إحصائيات شهرية برسم دائري، وتقدر تصدّر عملياتك لملف Excel (CSV).
- كل بياناتك تبقى على جوالك فقط.

---

## ١) طلّع ملف IPA من GitHub (مجانًا)

1. سوّ حساب في **github.com** إذا ما عندك.
2. اضغط **New repository**، سمّه `halala` واختر **Public**. البناء على ماك مجاني بدون حد للمستودع العام، أما الخاص فيستهلك من الدقائق المجانية.
3. في صفحة المستودع اضغط **uploading an existing file**، واسحب **كل محتويات** مجلد `Halala` (مو المجلد نفسه)، ثم **Commit changes**.
4. **مهم:** مجلد `.github` مخفي على الماك. تأكد إنه انرفع. إذا ما انرفع:
   - اضغط **Add file ← Create new file**
   - اكتب الاسم: `.github/workflows/build.yml`
   - انسخ محتوى الملف `build.yml` من المجلد والصقه، ثم **Commit**.
5. روح لتبويب **Actions**. بتلقى البناء شغّال (ياخذ تقريبًا ٥ إلى ٨ دقائق).
6. لما يصير ✅ افتح البناء، وتحت **Artifacts** نزّل **Halala-ipa**. فك الضغط وبتلقى `Halala.ipa`.

## ٢) ثبّته على جوالك بـ Sideloadly

1. نزّل **Sideloadly** من sideloadly.io (فيه نسخة لويندوز وماك).
2. وصّل الآيفون بالكمبيوتر بالكيبل.
3. اسحب `Halala.ipa` على Sideloadly، واكتب إيميل Apple ID حقك، واضغط **Start**.
4. في الجوال روح: **الإعدادات ← عام ← VPN وإدارة الأجهزة** واضغط **وثوق** على حسابك.
5. فعّل **وضع المطوّر**: **الإعدادات ← الخصوصية والأمن ← وضع المطوّر**، والجوال بيعيد التشغيل.

> ⚠️ مع Apple ID المجاني، التطبيق يشتغل **٧ أيام** وبعدها تحتاج تعيد التثبيت من Sideloadly. بياناتك ما تنمسح إذا ثبّته فوقه. وإذا عندك حساب مطوّر مدفوع، يشتغل سنة كاملة.

## ٣) خلّ رسائل البنك تنسجل تلقائيًا

1. افتح **الاختصارات ← الأتمتة ← +**.
2. اختر **رسالة**، وفي **الرسالة تحتوي على** اكتب `SAR` أو `مبلغ`.
3. اختر **تشغيل فورًا**، ثم **التالي**.
4. اختر **أتمتة فارغة جديدة ← إضافة إجراء**، وابحث عن **هللة** واختر **سجّل رسالة بنك**.
5. اضغط على **نص الرسالة** واختر **مدخلات الاختصار ← المحتوى**.

وخلاص، أي رسالة شراء أو حوالة توصلك تنضاف للتطبيق، وتطلع لك رسالة صغيرة بالمبلغ والفئة.

> التطبيق ما يقدر يدخل على حسابك البنكي مباشرة، لأن أبل والبنوك ما يسمحون بهذا لتطبيق شخصي. فيعتمد على رسائل البنك اللي توصلك، وهي فيها كل عملية.

### محتويات المشروع
| الملف | وش فيه |
|---|---|
| `Halala/*.swift` | كود التطبيق (SwiftUI + SwiftData) |
| `Halala/SMSParser.swift` | قراءة رسائل البنوك السعودية (الراجحي، الأهلي، الإنماء، وغيرها) |
| `Halala/LogSMSIntent.swift` | إجراء «سجّل رسالة بنك» في الاختصارات |
| `project.yml` | إعداد المشروع (XcodeGen) |
| `.github/workflows/build.yml` | البناء التلقائي على GitHub وإخراج IPA |

إذا عندك ماك: `brew install xcodegen && xcodegen generate`، وبعدها افتح `Halala.xcodeproj` وشغّله على جوالك.
